# MIGA-URBANA

Miga Urbana es una landing page para una panadería vegana de barrio, diseñada con una estética street art botánico.

El proyecto combina una identidad visual urbana y artesanal con una interfaz sencilla, clara y responsive.

Proyecto: Miga Urbana - Panadería vegana de barrio

La web presenta:
- Productos de panadería y bollería vegana
- Historia de la marca
- Información para visitar la panadería
- Diseño responsive para móvil, tablet y escritorio
- Identidad visual basada en tonos naturales y terracota

Diseño
La identidad visual utiliza:
- Terracota: #BF6341
- Crema: #F2E8DC
- Amarillo: #D9AF62
- Verde salvia: #94A681
- Verde musgo: #294028

Tipografías
